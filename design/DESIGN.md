# Design

## Core

A shell can be divided into 3 parts:

1. The Parser.
2. The Executor.
3. Shell Subsystems.

### Parser

Reads user input and puts it into a data structure that will inform the kind of commands to be executed.

### Executor

- Takes the data structure generated by the parser and create a new process.
- It is also responsible for creating pipes to communicate the output of one process to the input of the next one.
- It is also responsible for redirections to and between standard input, standard output and standard error.

### Shell Subsystems

Extends the operations of a shell.

## Guides

- POSIX standard.
