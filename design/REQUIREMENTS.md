# Requirements

## DESIGN GOALS

- [x] A parser that transforms user input into a data structure.
- [x] An executor that can take the data structure generated by the parser and perform actions.
- [ ] An executor that allows interprocess communication through pipes.
- [ ] An executor that allows redirection of stdin, stdout and stderr.

## CORE

- [x] Must be able to run other programs.
- [x] Must be able to create and view history of commands.
- [x] Must be able to define and use environment variables.
- [x] Must be able to handle user input.
- [x] Must display meaningful errors.
- [x] `cd` to track/change working directory.
- [x] Must allow graceful exit of shell process.
- [ ] Must be able to redirect input and output.
- [ ] Must be able to create pipelines for communication between commands.

## Shell Subsystems

- [ ] Room for plugins.
- [ ] Keyboard shortcuts.
- [ ] Shell Configuration.
- [ ] `alias` in the shell.
- [ ] Command autocompletion.
- [ ] File autocompletion.
- [ ] Must allow background processing and reporting.
