# Requirements

## GOALS

- [x] Allows direct interaction with the computer.

## CORE

- [x] Must be able to handle user input.
- [x] Must be able to run other programs.
- [x] Must be able to create and view history of commands.
- [x] Must be able to read and use environment variables.
- [ ] Must be able to set default environment variables for shell.
- [ ] Must be able to define environment variables in shell.
- [ ] Must have missing UNIX shell utilities (eg. cd, "~" as $HOME variable).
- [ ] Must be able to redirect input.
- [ ] Must be able to redirect output.
- [ ] Must be able to cycle through history of commands with keybinds.
- [ ] Must be able to allow file completions.
- [ ] Must be able to allow command completions.
- [ ] Must be able to create pipelines for communication between commands.
