# Requirements

## GOALS

- [ ] Allows direct interaction with the computer.

## CORE

- [ ] Must be able to run other programs.
- [ ] Must be able to redirect input and output.
- [ ] Must be able to create and view history of commands.
- [ ] Must be able to allow file completions.
- [ ] Must be able to define and use environment variables.
- [ ] Must be able to create pipelines for communication between commands.
- [ ] Must be able to handle user input.
