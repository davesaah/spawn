# Design

## Core

A shell can be divided into 3 parts:

1. The Parser.
2. The Executor.
3. Shell Subsystems.

### Parser

Reads user input and puts it into a data structure called **Command Table** that will store the commands that will be executed.

### Executor

- Takes the command table generated by the parser and for every command, it will create a new process.
- It is also responsible for creating pipes to communicate the output of one process to the input of the next one.
- It is also responsible for redirections to and between standard input, standard output and standard error.

### Shell Subsystems

- The use of environment variables.
- Processing of wildcards.
- The use of subshells.

## Features

- Built-in commands.
- Pipe detection.
- Redirect detection.
- Shell loop.
- Shell states.
- Background processing and reporting.
- Room for plugins.
- POSIX compliance.
- Keyboard shortcuts.
- Coloured output.
- Configuration.
- Shell alias.
- Autocompletion.

## Guides

- POSIX standard.
- Unix philosophy.
